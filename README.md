# 项目简介

## 核心功能
- 基于YOLOv8算法实现塑料表面缺陷检测
- 支持图片、视频及摄像头三种输入方式进行检测
- 提供实时显示功能，包括目标位置、目标总数和置信度信息
- 支持批量检测并直接查看所有检测结果
- 允许自定义置信度和IOU阈值
- 支持选择显示标签和原图
- 可选择不同的检测模型
- 支持保存检测结果

## 适用场景
- 塑料产品质量检测
- 工业生产线自动化检测
- 产品质量控制与评估
- 缺陷分类识别（BlackSpeck、Dirty、Scratches等）

## 技术特点
- 采用Pycharm+Anaconda或VSCode+Anaconda开发环境
- 基于Python 3.9，集成opencv-python、PyQt5、ultralytics和torch1.9等技术栈
- 包含2151张标注数据集，涵盖4类缺陷类型
- 提供完整源码、UI界面源文件、数据集和项目运行教程
- 已训练好模型，配置成功环境可直接使用
